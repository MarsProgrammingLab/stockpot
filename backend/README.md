# StockPot - Kitchen Inventory Manager Overview
StockPot is a full-stack kitchen inventory manager built with a Spring Boot REST API and two frontends including Vanilla JS and React. Track what's in your pantry, fridge, and freezer including quantities, categories, and storage locations, so you always know what's running low or about to expire. The app uses JWT authentication to keep your inventory private and personal.
